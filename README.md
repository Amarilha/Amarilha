**Engenheiro de Software com foco em DevSecOps.** Construo sistemas de ponta a ponta e os pipelines que os levam para produção com segurança.

- ☕ Back-end com **Java + Spring Boot**, JPA/Hibernate, Spring Security, APIs **REST e SOAP**, OO e Design Patterns
- 🗄️ **SQL** avançado: views, functions, procedures, índices e análise de **plano de execução**
- 💻 Front-end com **Angular** e **React / Next.js** em **TypeScript**
- 🔐 **DevSecOps**: SAST (CodeQL), SCA e scan de imagens (Trivy), SBOM, assinatura de imagens (Cosign), security gates
- ☸️ **DevOps**: Docker, Kubernetes, GitHub Actions, Prometheus, IaC
- 🤖 Uso **ferramentas de IA (Claude Code)** no dia a dia do desenvolvimento
